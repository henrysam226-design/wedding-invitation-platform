# wedding-invitation-platform

A polished wedding invitation platform MVP built with Next.js and Tailwind CSS.

## Features
- Invitation template gallery
- Customizable invitation builder
- Guest RSVP flow
- Wedding event details page
- Dashboard overview with mock analytics

## Getting started

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Demo
- Landing page: `/`
- Invitation preview: `/invite/ava-and-noah`
- Dashboard: `/dashboard`

## Notes
This is a frontend-focused MVP meant to demonstrate the platform experience and can be extended with authentication, database storage, and Stripe payments later.
